# EntityWithQualityID

_concept_

An entity prototype with optional quality specification. Can be specified in one of four ways.

**Definition:** [LuaEntity](../classes/LuaEntity.md) — The entity. Both prototype and quality of the entity will be used. ∣ [LuaEntityPrototype](../classes/LuaEntityPrototype.md) — The entity prototype. Normal quality will be used. ∣ [string](../concepts/string.md) — The prototype name. Normal quality will be used. ∣ [EntityIDAndQualityIDPair](../concepts/EntityIDAndQualityIDPair.md) — A table of entity prototype and quality.
