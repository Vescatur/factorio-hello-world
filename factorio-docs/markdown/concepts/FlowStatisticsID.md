# FlowStatisticsID

_concept_

Identifies a statistics prototype, depending on the statistics type.

**Definition:** [ItemWithQualityID](../concepts/ItemWithQualityID.md) — Used with item production statistics. ∣ [FluidID](../concepts/FluidID.md) — Used with fluid production statistics. ∣ [EntityWithQualityID](../concepts/EntityWithQualityID.md) — Used with electric network, entity build count, and kill count statistics. ∣ [EntityID](../concepts/EntityID.md) — Used with pollution statistics.
