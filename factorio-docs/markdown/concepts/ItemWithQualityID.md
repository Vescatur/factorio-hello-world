# ItemWithQualityID

_concept_

An item prototype with optional quality specification. Can be specified in one of four ways.

**Definition:** [LuaItemStack](../classes/LuaItemStack.md) — The item stack. Both prototype and quality of the item stack will be used. ∣ [LuaItemPrototype](../classes/LuaItemPrototype.md) — The item prototype. Normal quality will be used. ∣ [string](../concepts/string.md) — The prototype name. Normal quality will be used. ∣ [ItemIDAndQualityIDPair](../concepts/ItemIDAndQualityIDPair.md) — A table of item prototype and quality.
