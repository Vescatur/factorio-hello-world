# GuiLocation

_concept_

Screen coordinates of a GUI element in a [LuaGui](../classes/LuaGui.md). This uses the same format as [TilePosition](../concepts/TilePosition.md), meaning it can be specified either with or without explicit keys.

**Definition:** table{x, y} ∣ tuple[[int32](../concepts/int32.md), [int32](../concepts/int32.md)]
