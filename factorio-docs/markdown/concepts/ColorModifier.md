# ColorModifier

_concept_

Same as [Color](../concepts/Color.md), but red, green, blue and alpha values can be any floating point number, without any special handling of the range [1, 255].

**Definition:** table{a, b, g, r} ∣ tuple[[float](../concepts/float.md), [float](../concepts/float.md), [float](../concepts/float.md), [float](../concepts/float.md)]
