# TrainPathAchievementPrototype

_prototype_

**Prototype type string:** `type = "train-path-achievement"`

**Inherits from:** [AchievementPrototype](../prototypes/AchievementPrototype.md)

This prototype is used for receiving an achievement when the player has a specified train path length.

## Properties

| Name | Type | Optional |
| --- | --- | --- |
| [minimum_distance](#minimum-distance) | [double](../types/double.md) |  |

### minimum_distance

**Type:** [double](../types/double.md)

The achievement will trigger if a train path is longer than this.

**Example:**

```
amount = 1000
```
