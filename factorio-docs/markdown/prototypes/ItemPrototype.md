### auto_recycle

**Type:** [boolean](../types/boolean.md) · _optional_ · **Default:** `{'complex_type': 'literal', 'value': True}`

Whether the item should be included in the self-recycling recipes automatically generated by the quality mod.

This property is not read by the game engine itself, but the quality mod's data-updates.lua file. This means it is discarded by the game engine after loading finishes.

### burnt_result

**Type:** [ItemID](../types/ItemID.md) · _optional_ · **Default:** `{'complex_type': 'literal', 'value': ''}`

The item that is the result when this item gets burned as fuel.

### close_sound

**Type:** [Sound](../types/Sound.md) · _optional_

### color_hint

**Type:** [ColorHintSpecification](../types/ColorHintSpecification.md) · _optional_

Only used by hidden setting, support may be limited.

### dark_background_icon

**Type:** [FileName](../types/FileName.md) · _optional_

If this is set, it is used to show items in alt-mode instead of the normal item icon. This can be useful to increase the contrast of the icon with the dark alt-mode [icon outline](../prototypes/UtilityConstants.md#item-outline-color).

Path to the icon file.

Only loaded if `dark_background_icons` is not defined.

### dark_background_icon_size

**Type:** [SpriteSizeType](../types/SpriteSizeType.md) · _optional_ · **Default:** `{'complex_type': 'literal', 'value': 64}`

The size of the square icon, in pixels. E.g. `32` for a 32px by 32px icon. Must be larger than `0`.

Only loaded if `dark_background_icons` is not defined.

### dark_background_icons

**Type:** array[[IconData](../types/IconData.md)] · _optional_

Can't be an empty array.

### default_import_location

**Type:** [SpaceLocationID](../types/SpaceLocationID.md) · _optional_ · **Default:** `{'complex_type': 'literal', 'value': 'nauvis'}`

### destroyed_by_dropping_trigger

**Type:** [Trigger](../types/Trigger.md) · _optional_

The effect/trigger that happens when an item is destroyed by being dropped on a [TilePrototype](../prototypes/TilePrototype.md) marked as destroying dropped items.

This overrides the [TilePrototype::default_destroyed_dropped_item_trigger](../prototypes/TilePrototype.md#default-destroyed-dropped-item-trigger) from the tile.

### drop_sound

**Type:** [Sound](../types/Sound.md) · _optional_

### flags

Specifies some properties of the item.

**Example:**

```
flags = { "hide-from-bonus-gui" }
```

### fuel_acceleration_multiplier

**Type:** [double](../types/double.md) · _optional_ · **Default:** `{'complex_type': 'literal', 'value': 1.0}`

Must be 0 or positive.

### fuel_acceleration_multiplier_quality_bonus

**Type:** [double](../types/double.md) · _optional_

Additional fuel acceleration multiplier per quality level. Defaults to 30% of `fuel_acceleration_multiplier - 1` if `fuel_acceleration_multiplier` is larger than 1. Otherwise defaults to 0.

Must be 0 or positive.

### fuel_category

**Type:** [FuelCategoryID](../types/FuelCategoryID.md) · _optional_ · **Default:** `{'complex_type': 'literal', 'value': ''}`

Must exist when a nonzero fuel_value is defined.

### fuel_emissions_multiplier

**Type:** [double](../types/double.md) · _optional_ · **Default:** `{'complex_type': 'literal', 'value': 1.0}`

### fuel_glow_color

**Type:** [Color](../types/Color.md) · _optional_

Colors the glow of the burner energy source when this fuel is burned. Can also be used to color the glow of reactors burning the fuel, see [ReactorPrototype::use_fuel_glow_color](../prototypes/ReactorPrototype.md#use-fuel-glow-color).

### fuel_top_speed_multiplier

**Type:** [double](../types/double.md) · _optional_ · **Default:** `{'complex_type': 'literal', 'value': 1.0}`

Must be 0 or positive.

### fuel_top_speed_multiplier_quality_bonus

**Type:** [double](../types/double.md) · _optional_

Additional fuel top speed multiplier per quality level. Defaults to 30% of `fuel_top_speed_multiplier - 1` if `fuel_top_speed_multiplier` is larger than 1. Otherwise defaults to 0.

Must be 0 or positive.

### fuel_value

**Type:** [Energy](../types/Energy.md) · _optional_ · **Default:** `{'complex_type': 'literal', 'value': '0J'}`

Amount of energy the item gives when used as fuel.

Mandatory if `fuel_acceleration_multiplier`, `fuel_top_speed_multiplier` or `fuel_emissions_multiplier` or `fuel_glow_color` are used.

**Example:**

```
fuel_value = "12MJ"
```

### moved_to_hub_when_building

**Type:** [boolean](../types/boolean.md) · _optional_

Whether this item should be moved to the hub when space platform performs building, upgrade or deconstruction and is left with this item. The following items are considered valuable and moved to hub by default: [Modules](../prototypes/ModulePrototype.md), [items that build entities](../prototypes/ItemPrototype.md#place-result), [items that build tiles](../prototypes/ItemPrototype.md#place-as-tile) and items [not obtainable from asteroid chunks](../prototypes/AsteroidChunkPrototype.md#minable) that have [subgroup](../prototypes/PrototypeBase.md#subgroup) from a [group](../prototypes/ItemSubGroup.md#group) other than `"intermediate-products"`.

### pictures

**Type:** [SpriteVariations](../types/SpriteVariations.md) · _optional_

Used to give the item multiple different icons so that they look less uniform on belts. For inventory icons and similar, `icon/icons` will be used. Maximum number of variations is 16.

When using sprites of size `64` (same as base game icons), the `scale` should be set to 0.5.

### place_result

**Type:** [EntityID](../types/EntityID.md) · _optional_ · **Default:** `{'complex_type': 'literal', 'value': ''}`

Name of the [EntityPrototype](../prototypes/EntityPrototype.md) that can be built using this item. If this item should be the one that construction bots use to build the specified `place_result`, set the `"primary-place-result"` [item flag](../types/ItemPrototypeFlags.md).

The localised name of the entity will be used as the in-game item name. This behavior can be overwritten by specifying `localised_name` on this item, it will be used instead.

**Example:**

```
place_result = "wooden-chest"
```

**Type:** [Color](../types/Color.md) · _optional_ · **Default:** `Value of UtilityConstants::item_default_random_tint_strength`

### send_to_orbit_mode

**Type:** [SendToOrbitMode](../types/SendToOrbitMode.md) · _optional_ · **Default:** `{'complex_type': 'literal', 'value': 'not-sendable'}`

The way this item works when we try to send it to the orbit on its own.

When "manual" is set, it can only be launched by pressing the launch button in the rocket silo.

When "automated" is set, it will force the existence of "launch to orbit automatically" checkbox in the rocket silo which will then force the silo to automatically send the item to orbit when present.

### space_platform_request_priority

**Type:** [boolean](../types/boolean.md) · _optional_ · **Default:** `{'complex_type': 'literal', 'value': False}`

Used by space platforms to prioritize item requests and make sure there is enough space for priority items before requesting the rest.

### spoil_level

**Type:** [uint8](../types/uint8.md) · _optional_ · **Default:** `{'complex_type': 'literal', 'value': 0}`

Used by Inserters with spoil priority. Item with higher spoil level is considered more spoiled than item with lower spoil level regardless of progress of spoiling.

### spoil_quality_change

**Type:** [int8](../types/int8.md) · _optional_ · **Default:** `{'complex_type': 'literal', 'value': 0}`

Defines how many levels the item's quality will go up (positive integer) or down (negative integer) when spoiling.

### spoil_quality_max

**Type:** [QualityID](../types/QualityID.md) · _optional_

The maximum quality level that can be reached when [spoil_quality_change](../prototypes/ItemPrototype.md#spoil-quality-change) is used.

### spoil_quality_min

**Type:** [QualityID](../types/QualityID.md) · _optional_

### weight

**Type:** [Weight](../types/Weight.md) · _optional_

The default weight is calculated automatically from recipes and falls back to [UtilityConstants::default_item_weight](../prototypes/UtilityConstants.md#default-item-weight).

More information on how item weight is determined can be found on its [auxiliary page](../auxiliary/item-weight.md).
