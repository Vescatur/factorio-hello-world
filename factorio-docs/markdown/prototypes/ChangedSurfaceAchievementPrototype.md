# ChangedSurfaceAchievementPrototype

_prototype_

**Prototype type string:** `type = "change-surface-achievement"`

**Inherits from:** [AchievementPrototype](../prototypes/AchievementPrototype.md)

This prototype is used for receiving an achievement when the player changes to a surface.

## Properties

| Name | Type | Optional |
| --- | --- | --- |
| [surface](#surface) | [string](../types/string.md) | yes |

### surface

**Type:** [string](../types/string.md) · _optional_

This will trigger the achievement, if the player changes to this surface.

**Example:**

```
surface = "fulgora"
```
