# TipsAndTricksItemCategory

_prototype_

**Prototype type string:** `type = "tips-and-tricks-item-category"`

A [TipsAndTricksItem](../prototypes/TipsAndTricksItem.md) category, used for sorting of tips and tricks entries: Tips and trick entries are sorted first by category and then by their order within that category.

### name

**Type:** [string](../types/string.md)

### order

**Type:** [Order](../types/Order.md)

Tips and trick categories are sorted by `order`, and then the tips and tips entries are sorted by their own order within those categories.
