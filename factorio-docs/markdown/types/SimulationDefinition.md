# SimulationDefinition

_type_

Used by tips and tricks and main menu simulations. Simulations can be controlled at runtime via [LuaSimulation](../classes/LuaSimulation.md).

### checkboard

**Type:** [boolean](../types/boolean.md) · _optional_ · **Default:** `{'complex_type': 'literal', 'value': True}`

If this is true, the map of the simulation is set to be a lab-tile checkerboard in the area of `{{-20, -15},{20, 15}}` when the scenario is first initialized (before init/init_file run).

### game_view_settings

**Type:** [GameViewSettings](../types/GameViewSettings.md) · _optional_

Only applied to the simulation if a test player is created through [LuaSimulation::create_test_player](../classes/LuaSimulation.md#create-test-player).

### generate_map

**Type:** [boolean](../types/boolean.md) · _optional_ · **Default:** `{'complex_type': 'literal', 'value': False}`

If `save` is not given and this is true, a map gets generated by the game for use in the simulation.

### hide_factoriopedia_gradient

**Type:** [boolean](../types/boolean.md) · _optional_

### hide_health_bars

**Type:** [boolean](../types/boolean.md) · _optional_ · **Default:** `{'complex_type': 'literal', 'value': True}`

### init

**Type:** [string](../types/string.md) · _optional_ · **Default:** `{'complex_type': 'literal', 'value': ''}`

Only loaded if `init_file` is not defined.

This code is run as a (silent) console command inside the simulation when it is first initialized. Since this is run as a console command, the restrictions of console commands apply, e.g. `require` is not available, see [here](../auxiliary/libraries.md).

### init_file

**Type:** [FileName](../types/FileName.md) · _optional_

This code is run as a (silent) console command inside the simulation when it is first initialized. Since this is run as a console command, the restrictions of console commands apply, e.g. `require` is not available, see [here](../auxiliary/libraries.md).

### init_update_count

**Type:** [uint32](../types/uint32.md) · _optional_ · **Default:** `{'complex_type': 'literal', 'value': 0}`

Amount of ticks that this simulation should run for before the simulation is shown to the player. These updates happen after init/init_file has been run and at the highest possible rate (> 60 UPS).

### length

**Type:** [uint32](../types/uint32.md) · _optional_ · **Default:** `{'complex_type': 'literal', 'value': 0}`

How long this simulation takes. In the main menu simulations, another simulation will start after this simulation ends.

### mods

**Type:** array[[string](../types/string.md)] · _optional_

An array of mods whose runtime scripts will be loaded for this simulation, if they are present and enabled.

### mute_alert_sounds

**Type:** [boolean](../types/boolean.md) · _optional_ · **Default:** `{'complex_type': 'literal', 'value': True}`

### mute_technology_finished_sound

**Type:** [boolean](../types/boolean.md) · _optional_ · **Default:** `{'complex_type': 'literal', 'value': True}`

### mute_wind_sounds

**Type:** [boolean](../types/boolean.md) · _optional_

Overrides whether a simulation has its wind sounds muted.

Tips and Tricks simulations and Factoriopedia simulations have their wind sounds muted by default, other simulations don't.

### override_volume

**Type:** [boolean](../types/boolean.md) · _optional_

If true, overrides the simulation volume set by the player in the sound settings, simply setting the volume modifier to `1`.

### planet

**Type:** [SpaceLocationID](../types/SpaceLocationID.md) · _optional_ · **Default:** `{'complex_type': 'literal', 'value': 'nauvis'}`

### save

**Type:** [FileName](../types/FileName.md) · _optional_

The save file that is used for this simulation. If not given and `generate_map` is `true`, a map is generated by the game.

### update

**Type:** [string](../types/string.md) · _optional_ · **Default:** `{'complex_type': 'literal', 'value': ''}`

Only loaded if `update_file` is not defined.

This code is run as a (silent) console command inside the simulation every time the simulation is updated. Since this is run as a console command, the restrictions of console commands apply, e.g. `require` is not available, see [here](../auxiliary/libraries.md).

### update_file

**Type:** [FileName](../types/FileName.md) · _optional_

This code is run as a (silent) console command inside the simulation every time the simulation is updated. Since this is run as a console command, the restrictions of console commands apply, e.g. `require` is not available, see [here](../auxiliary/libraries.md).

### volume_modifier

**Type:** [float](../types/float.md) · _optional_

Multiplier for the simulation volume set by the player in the sound settings.
