# AttackParameters

_type_

Loaded as one of the [BaseAttackParameters](../types/BaseAttackParameters.md) extensions, based on the value of the `type` key.

**Definition:** [ProjectileAttackParameters](../types/ProjectileAttackParameters.md) — Loaded when the `type` is `"projectile"`. ∣ [BeamAttackParameters](../types/BeamAttackParameters.md) — Loaded when the `type` is `"beam"`. ∣ [StreamAttackParameters](../types/StreamAttackParameters.md) — Loaded when the `type` is `"stream"`.
