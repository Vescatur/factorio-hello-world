# RandomRange

_type_

Define a numerical property in terms of minimum and maximum to be used as a randomly chosen value in that range (inclusively).

The maximum cannot be less than the minimum.

**Definition:** tuple[[uint8](../types/uint8.md), [uint8](../types/uint8.md)] — First number is the minimum, second is the maximum. ∣ [uint8](../types/uint8.md) — The same minimum and maximum.
