# IngredientPrototype

_type_

Item or fluid ingredient.

**Examples:**

```
{type="item", name="steel-plate", amount=8} -- item ingredient
```

```
{type="fluid", name="water", amount=50} -- fluid ingredient
```

**Definition:** [ItemIngredientPrototype](../types/ItemIngredientPrototype.md) — Loaded when the `type` is `"item"`. ∣ [FluidIngredientPrototype](../types/FluidIngredientPrototype.md) — Loaded when the `type` is `"fluid"`.
