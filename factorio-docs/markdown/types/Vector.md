# Vector

_type_

A vector is a two-element array or dictionary containing the x and y components. Positive x goes east, positive y goes south.

**Examples:**

```
shift = {0, 12}
```

```
right = {1.0, 0.5}
```

```
vector = {x = 2.3, y = 3.4}
```
