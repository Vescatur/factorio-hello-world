# CloudEffectStyle

_type_

Additional mask which dictates where in the world certain [ProcessionLayers](../types/ProcessionLayer.md) are drawn. Origin determined by [EffectRelativeTo](../types/EffectRelativeTo.md).

**Definition:** `"none"` ∣ `"euclidean"` ∣ `"manhattan"` ∣ `"euclidean-outside"` ∣ `"manhattan-outside"` ∣ `"horizontal-stripe"` ∣ `"texture"` ∣ `"texture-outside"`
