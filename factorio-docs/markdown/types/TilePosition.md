# TilePosition

_type_

Coordinates of a tile on a map where each integer `x`/`y` represents a different tile. This uses the same format as [MapPosition](../types/MapPosition.md), except it rounds any non-integer `x`/`y` down to whole numbers. It can be specified either with or without explicit keys.
